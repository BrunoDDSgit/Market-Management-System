# Market-Management-System
Sistema de gerenciamento de mercadinho desenvolvido em Java com Spring Boot,  aprofundando desenvolvimento de APIs REST, integração com banco de dados, autenticação e operações CRUD. O projeto busca utilizar arquitetura em camadas, padrões de projeto, persistência de dados, versionamento com Git e desenvolvimento colaborativo.
